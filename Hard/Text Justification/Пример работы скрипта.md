words = ["This", "is", "an", "example", "of", "text"]  
maxWidth = 16  

После работы цикла первая строка содержит три слова:  

["This", "is", "an"]  

Их общая длина без пробелов: 4 + 2 + 2 = 8  

Количество промежутков: 3 - 1 = 2  

Теперь рассчитываем пробелы:  

total_spaces = 16 - 8 		  # 8  
spaces_per_gap = 8 // 2 	  # 4  
extra_spaces = 8 % 2 		    # 0  

Получаем строку:  

This	is 	an  

Между This и is четыре пробела, и между is и an тоже четыре.  
Общая длина - 16 символов.  
А что происходит с последней строкой?  
Например, если осталось:  

["of", "text"]  

Срабатывает условие j == n, поскольку больше необработанных слов нет.  
Поэтому используется:  

line = " ".join(words[i:j])  
line += " " * (maxWidth - len(line))  

Сначала слова объединяются одним пробелом:  

of text  

Длина полученной строки - 7 символов. Значит, справа добавляется 9 пробелов,  
чтобы итоговая длина стала равна 16.  

* if j == n or num_pags == 0 - выравниваем строку по левому краю.  
* else - равномерно распределяем пробелы между словами.  
* spaces_per_gap - базовое количество пробелов в каждом промежутке.  
* extra_spaces - количество оставшихся пробелов, которые нужно распределить слева направо.  
* parts - собирает слова и пробелы по частям.  
* i = j - переходим к следующим необработанным словам.  
* return result - возвращаем все готовые строки.
