68. Text Justification  
Дано.  

Дан массив строк words и целое число maxWidth. Необходимо отформатировать текст так, чтобы каждая строка  
имела ровно maxWidth символов и была выровнена по ширине (по левому и по правому краю).  

Слова нужно распределять по строкам жадным алгоритмом (greedy), то есть помещать в каждую строку  
максимально возможное количество слов.  

Если необходимо, добавлять пробелы ' ', чтобы длина каждой строки составляла ровно maxWidth символов.  
 
Правила распределения пробелов:  
1. Дополнительные пробелы между словами должны распределяться максимально равномерно.  
2. Если пробелы нельзя распределить поровну, то левые промежутки получают больше пробелов, чем правые.  
3. Последняя строка должна быть выровнена по левому краю: между словами ставится ровно один пробел,  
а оставшееся пространство заполняется пробелами справа.  
4. Если в строке находится только одно слово, оно также выравнивается по левому краю, а оставшееся  
место заполняется пробелами справа.  

Пример.  
Входные данные:  
words = ["This", "is", "an", "example", "of", "text", "justification."]  
maxWidth = 16  

Результат:  

[  
    "This    is    an",  
    "example    of  text",  
    "justification.     "  
]  

В первой строке между словами распределены пробелы так:  

 This___is___an  

Здесь _ обозначает один пробел. Между This и is - четыре пробела и между is и an - тоже четыре.  
В последней строке слово justification дополняется пробелами справа.  
 
Ограничения:  
1 <= len(words) <= 300  
1 <= len(words[i]) <= 20  
1 <= maxWidth <= 100  
Длина каждого слова не превышает maxWidth.  
Слова состоят из английских букв и символов.
