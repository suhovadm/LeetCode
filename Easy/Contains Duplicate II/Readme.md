219. Contains Duplicate II.  

Дан целочисленный массив nums и целое число k.  

Верните true, если в массиве существуют два различных индекса i и j, таких что:  

* nums[i] == nums[j] - значения элементов равны;  
* abs(i - j) <= k - абсолютная разница между индексами не превышает k.  

В противном случае верните false.  
_________________________________________________________________________________  

Пример 1.  
Ввод:  
nums = [1, 2, 3, 1]  
k = 3  

Вывод:  
true  

Нам нужно найти два одинаковых числа, расстояние между индексами которых не превышает k = 3.  
Индексы массива начинаются с нуля.  
В массиве число 1 встречается 2 раза.  
Первый раз: индекс 0.  
Второй раз: индекс 3.  
Вычисляем расстояние: abs(0 - 3) = 3  
Сравниваем с k: 3 <= 3 // True  
_________________________________________________________________________________  

Пример 2.  
Ввод:  
nums = [1, 0, 1, 1]  
k = 1  

Вывод:  
true  

Число 1 встречается 3 раза:  
Первый раз: индекс 0.  
Второй раз: индекс 2.  
Третий раз: индекс 3.  
Вычисляем расстояние: abs(2 - 3) = 1  
Сравниваем: 1 <= 1 // True  
_________________________________________________________________________________  
Пример 3.  
Ввод:  
nums = [1, 2, 3, 1, 2, 3]  
k = 2  

Вывод:  
false  

Число 1: индексы 0 и 3 -> abs(0 - 3) = 3.  
Число 2: индексы 1 и 4 -> abs(1 - 4) = 3.  
Число 3: индексы 2 и 5 -> abs(2 - 5) = 3.  
Сравниваем каждое расстояние с k=2: 3 <= 2 // False  
_________________________________________________________________________________
