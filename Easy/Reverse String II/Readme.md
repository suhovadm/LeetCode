Дана строка s и целое число k. Необходимо переворачивать первые k символов в каждом блоке  
из 2k символов, начиная с начала строки.  

* Если осталось меньше k символов, переверните все оставшиеся символы.  
* Если осталось меньше 2k, но не меньше k символов, переверните первые k символов,  
а остальные оставьте без изменений.  

Пример 1:  

Ввод: s = "abcdefg", k = 2  
Вывод: "bacdfeg"  

Пример 2:  

Ввод: s = "abcd", k = 2  
Вывод: "bacd"
