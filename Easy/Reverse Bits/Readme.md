190. Reverse Bits.  

Развернуть биты заданного 32-битного целого числа.  

* Пример 1.  

Входные данные:  
n = 43261596  

Выходные данные:  
964176192  

Целое число	Двоичное представление  
43261596	00000010100101000001111010011100  
964176192	00111001011110000010100101000000  
___________________________________________________  

* Пример 2.  

Входные данные:  
n = 2147483644  
  
Выходные данные:  
1073741822  

Целое число	Двоичное представление  
2147483644	01111111111111111111111111111100  
1073741822	00111111111111111111111111111110  
___________________________________________________  

Суть задачи: необходимо изменить порядок всех 32 бит  
заданного целого числа на противоположный: первый бит  
становится последним, второй - предпоследним и так далее.  

То есть, мы переводим входные данные в двоичку,  
переводим порядок всех 32 бит на противоположный,  
а затем переводим это обратно в целое число. Всё.  
___________________________________________________
