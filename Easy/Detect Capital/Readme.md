Дано.  
Мы считаем, что использование заглавных букв в слове является правильным, если выполняется одно из следующих условий:  
 
Все буквы в слове заглавные, например "USA".  
Все буквы в слове строчные, например "leetcode".  
Только первая буква в слове заглавная, например "Google".  

Дана строка word. Верните true, если использование заглавных букв в ней является правильным.  

Примеры.  

Пример 1:  

Ввод: word = "USA"  
Вывод: true  

Пример 2:  

Ввод: word = "FlaG"  
Вывод: false  

Ограничения.  

* 1 ≤ word.length ≤ 100  
* Строка word состоит из строчных и заглавных букв английского алфавита.
