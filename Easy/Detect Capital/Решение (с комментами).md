    def detectCapitalUse(self, word: str) -> bool:  

isupper() — все буквы заглавные, например "USA".  
islower() — все буквы строчные, например "leetcode"  
istitle() — только первая буква заглавная, например "Google".  
or - логическое "или" - если хотя бы одна проверка вернула True, результат будет True.  
        return word.isupper() or word.islower() or word.istitle()  

Итог: метод возвращает True, если слово написано по одному из трёх правил  
использования заглавных букв, иначе возвращает False.
